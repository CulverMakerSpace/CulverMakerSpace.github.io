Coxswain Training Simulator

Controls

Prep Commands

ShiftAll
QPort
PStarboard

Execution Commands

WForward
SReverse
SpaceCoast/Let it run
EnterHold water
URaise oars
JLower oars

All of the above controls require a prep key followed by an execution key. Pressing a second prep key changes the selected rowers.

Coxswain Controls

↕Increase/Decrease stroke rate 1
↔Adjust rudder by 10°

Camera Controls

MToggle map/boat views
+/-Zoom in/out
