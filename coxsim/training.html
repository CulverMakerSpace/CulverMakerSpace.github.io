Coxswain Training Simulator

Controls

Prep Commands

ShiftAll
QPort
PStarboard

Action Commands

WForward
SReverse
SpaceCoast / Let it run
EnterHold water
URaise oars
JLower oars

Command Modifiers

CtrlFOR a number of strokes
AltIN a number of strokes
1-9Select stroke count (1-9)
`Enter second digit to count (10–20)
TabAdd a follow-up command

Command Management

GGo / Execute prepared command
CClear prepared command

Enter commands in sequence: Prep → Modifier + Stroke Count (optional) → Action → G.
Nothing executes until G is pressed. Press C to clear the prepared command.
A follow-up command can be sent at the same time by pressing TAB → Prep' → Action' before pressing G.

Coxswain Controls

↕Increase / Decrease stroke rate by 1 spm
↔Adjust rudder by 10°

Camera Controls

MToggle map / boat views
+/-Zoom in / out
