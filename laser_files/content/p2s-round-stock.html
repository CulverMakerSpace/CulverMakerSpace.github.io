xTool P2S: Completing a Job on Round Stock

Round objects require a different setup because the surface being engraved continually changes direction. The xTool Rotary Attachment rotates the object while the laser moves across it, allowing the P2S to engrave cylindrical objects.

Common examples include tumblers, cups, bottles, and cylindrical containers.

MEDIA PLACEHOLDER: Photo of the rotary attachment installed in the P2S with a sample tumbler.

1. Prepare the Machine

Configure the machine for the rotary attachment and connect the attachment as required. Do not attempt to change the rotary setup while the machine is operating.

2. Mount the Object

Place the object securely on the rotary attachment. The object must rotate smoothly without slipping, rocking, or shifting.

3. Select Rotary Mode

In xTool Studio, select the appropriate rotary processing mode and the rotary configuration being used.

4. Enter or Measure the Object Dimensions

The software needs accurate information about the object's size and position so it can map the design correctly around the surface. Follow the measurement procedure shown in xTool Studio.

5. Position the Design

Place the design over the desired portion of the object's surface. Remember that the flat design shown on the computer will ultimately be wrapped around a three-dimensional object.

6. Select Processing Settings

Choose the correct material and engraving settings. Most rotary projects will use Engrave or Score rather than Cut.

7. Preview

Verify the location and orientation of the design. Pay particular attention to rotation, centering, size, and the available engraving area.

8. Start and Monitor the Job

Start the job and remain with the machine for the entire process. Watch the object to make sure it continues rotating correctly and does not slip.
