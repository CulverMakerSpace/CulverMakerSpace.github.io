xTool Studio: Initial Setup

Before preparing a project, xTool Studio needs to be connected to the correct machine and set to the appropriate processing mode.

Connect to the P2S

Open xTool Studio and create a new project. In the device area, select or connect to the xTool P2S. Always confirm the correct machine before changing material or process settings.

MEDIA PLACEHOLDER: Screenshot or short video showing how to connect xTool Studio to the P2S.

Select the Processing Mode

For most projects in this introductory training, you will use one of two modes:

  • Process on Slats — used for most jobs involving flat sheet material.
  • Rotary Processing — used when engraving cylindrical or round objects with the rotary attachment.

The P2S supports additional processing modes and accessories. Those options can be useful for specialized projects, but they are not necessary for normal operation and are not part of this introductory training.

Before You Continue

Confirm that the P2S is connected, the correct processing mode is selected, and the machine is ready before importing and positioning your final design.
