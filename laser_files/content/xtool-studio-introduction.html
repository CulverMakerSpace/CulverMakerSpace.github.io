xTool Studio: Introduction

xTool Studio is the software we use to prepare projects for the xTool P2S. While the P2S performs the actual cutting and engraving, xTool Studio tells the machine what to process, where to process it, and how to process it.

Designs can be created directly in xTool Studio or imported from other programs. For example, a precisely dimensioned part might be created in CAD software and then imported into xTool Studio for cutting.

Three Basic Operations

Cut — The laser follows a vector path and passes completely through the material. Cut is normally used to create outside edges, holes, slots, and other features that need to be physically removed.

Score — The laser follows a vector path but does not cut completely through the material. This creates a thin line on the surface and can be useful for labels, fold lines, alignment marks, or decorative details.

Engrave — Instead of simply tracing a line, the laser moves across an area and removes or changes the surface of the material. Engraving is commonly used for text, logos, photographs, and patterns.

A single project can use more than one operation. For example, a name could be engraved onto a wooden panel before the panel is cut out.
