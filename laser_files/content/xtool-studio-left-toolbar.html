xTool Studio: Left Toolbar

The toolbar on the left side of the xTool Studio workspace contains tools for adding and creating objects in your project. You will not need every tool in this panel for normal projects, so this training focuses on the most common ones.

MEDIA PLACEHOLDER: Screenshot of the left toolbar with the tools below labeled.

Import

Use the import tool to add an existing design from your computer. Common files used for laser work include vector files such as SVG and DXF and bitmap images such as PNG and JPG.

Text

The Text tool allows you to create text directly in xTool Studio. After creating the text, you can change its font, size, alignment, and other properties. Text is commonly engraved, but it can also be incorporated into vector designs.

Shape

The Shape tool provides basic geometric objects such as rectangles, circles, and polygons. For simple projects, these tools may eliminate the need to create a separate CAD file.

Vector and Drawing Tools

Vector tools allow you to create or modify paths directly inside xTool Studio. Vector paths are especially important for Cut and Score operations because they define the path the laser will follow.

Other Tools

xTool Studio contains additional design and editing tools. You are encouraged to explore them, but they are not required for completing a basic laser-cutting job.
