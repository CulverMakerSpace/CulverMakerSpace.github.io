Preparing Designs for the Laser

Laser cutters work primarily with two kinds of digital graphics: vectors and bitmaps. Understanding the difference will help you choose the correct file type and processing operation.

Vector Graphics

Vector graphics describe objects using mathematical paths. A circle, for example, is stored as the geometry of a circle rather than as a grid of individual pixels. Vector graphics are ideal for cutting, scoring, and precisely dimensioned geometry. SVG and DXF are common vector file formats used for laser projects.

Bitmap Images

Bitmap, or raster, images are made from pixels. Photographs and many PNG or JPG files are bitmap images. They are commonly used for engraving.

Closed and Open Paths

A vector path does not necessarily form a closed shape. A closed path returns to its starting point and can define a complete enclosed region. An open path has two ends.

Open paths are useful for scoring lines, but an accidentally open outline can prevent a part from being cut out as intended.

Duplicate Lines

One of the most common problems in laser-cut files is duplicate geometry. Two identical vector lines can occupy exactly the same location and appear to be a single line on the screen. The laser, however, may process both lines and travel over the same location twice.

This increases processing time and can cause unnecessary burning or heating. Always inspect imported designs for duplicate geometry.

Assign Operations Intentionally

Every object in the design should have a purpose. Before processing the job, ask whether each object should be cut, scored, or engraved. Do not rely only on how the design looks on screen; check the operation assigned to each object.
